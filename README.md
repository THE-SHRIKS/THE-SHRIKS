## Order cut from complexity.

**THE SHRIKS** is an independent, India-based technology venture working across system architecture, custom engineering, AI systems, software infrastructure, owned products, and media IP.

Founded and led by **Laukik Rajput**, the practice brings product strategy and technical execution into the same room. Work can begin as an architecture problem, a product experiment, an engineering collaboration, or an original creative direction. The standard remains the same: understand the constraints, build deliberately, and verify what works.

<br/>

### 02 &nbsp; / &nbsp; Selected engineering

**[SAAR](https://github.com/THE-SHRIKS/SAAR-LokiXPiyush)**  
A local-first financial intelligence desktop application, developed in collaboration with Piyush. Document ingestion, reconciliation, and grounded interaction with financial records.

**[R2-D2 / AgentDeck](https://github.com/THE-SHRIKS/R2-D2)**  
An Android control surface and local-network bridge for observing and directing compatible desktop AI coding-agent sessions.

**[Open Lite Discord](https://github.com/THE-SHRIKS/Open-Lite-Discord)**  
An experiment in reconstructing the core of a community communication system with local infrastructure, persistent state, roles, and real-time interactions.

**[ENMAS](https://github.com/THE-SHRIKS/ENMAS)**  
The engineering behind a connected set of original creative experiences, including interactive worlds and editorial media surfaces.

### 03 &nbsp; / &nbsp; Working principles

```text
01  ARCHITECTURE    Understand the system before multiplying its parts.
02  ENGINEERING     Design for the constraints that actually exist.
03  VERIFICATION    Treat a passing demonstration as evidence, not a conclusion.
04  OWNERSHIP       Build reusable capabilities, not disposable appearances.
05  CREATIVE WORK   Give original ideas the same rigor as technical systems.
```
